# chronic-ai

---

## 📊 Data Sources

- **Patient Profiles:** Contain demographics, medical history, and health targets.  
- **Vitals Data:** 10-day logs of heart rate, BP, oxygen levels, and activity.  
- **Reports:** AI-generated doctor alerts and weekly patient summaries.  

---

## 🧠 Learnings & Findings

- Built an **autonomous agentic AI workflow** for decision-making.  
- Integrated **Gemini API** for real-time medical reasoning and text generation.  
- Designed a **secure FastAPI + React full-stack** architecture.  
- Learned to manage **data pipelines and alert automation** using cloud services.

---

## 💡 Future Scope

- Integration with **wearables** (Fitbit, Apple Watch, etc.) for live data.  
- Adding **predictive analytics** for forecasting potential health risks.  
- **Multi-patient dashboards** for hospitals and healthcare providers.  
- Integration with **EHR/EMR systems** for real-time medical record syncing.
